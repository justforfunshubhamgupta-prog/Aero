# Aero

A lightweight, privacy-first utility suite for Windows.

Aero brings together small tools that solve everyday annoyances without requiring an account, cloud service, or AI subscription.

## Features

### Clipboard
- Searchable clipboard history
- Pin frequently used items
- Quickly restore copied content
- Local storage

### Screenshot Organizer
- Organize screenshots
- OCR and text search
- Categorization
- Duplicate detection

### Reminders
- Fast reminders
- Natural-language input
- Windows notifications

### Link Analyzer
- Inspect URLs before opening
- Redirect analysis
- Basic security indicators
- Local-first processing where possible

### Smart Paste
- Transform messy copied information into structured content
- Optional AI assistance
- Core functionality remains usable without AI

## Principles

- **Local-first**
- **Privacy-first**
- **No mandatory account**
- **No mandatory cloud**
- **No mandatory AI**
- **Low resource usage**
- **Open source**

## Technology

- C#
- .NET 10
- WPF
- SQLite
- SQLite FTS5
- xUnit
